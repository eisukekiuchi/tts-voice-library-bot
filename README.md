# TTS Voice Library Bot

Discordの読み上げBOTを、一般メンバーがコマンドを覚えなくても使えるようにしたボタン式BOTです。

## 一般メンバーの操作

- VC接続 / 切断
- 読み上げON / OFF
- スキップ
- ボイス一覧
- お気に入り
- ボイス検索
- このチャンネルを読む
- 速度変更
- 音量変更
- 混雑状況
- 各ボイスのVC試聴 / 音声ファイル試聴 / 選択

検索と辞書登録は、Discordのボタンを押したあとに開く入力ウィンドウを使います。スラッシュコマンド入力は不要です。

## 大量入力・長文対応

- TTS生成を並列化
- 長文を自然な位置で自動分割
- 後続メッセージも先行生成
- VC再生順はDiscord投稿順を維持
- 同文・同声・同設定は音声キャッシュ再利用
- 同一生成の重複実行を抑止
- バックログ上限あり

## Railway

状態保存と音声キャッシュは DATA_DIR / CACHE_DIR に保存します。
Railway Volumeを /data にマウントする構成を推奨します。

必須:
- DISCORD_TOKEN

Discord Developer Portalでは MESSAGE CONTENT INTENT を有効にしてください。

音声エンジンは VOICEVOX互換HTTP APIを利用します。
VOICEVOX / AivisSpeech などをENGINE_ENDPOINTSに登録できます。

## ネットスラング・ゲーム用語の読み上げ辞書

2026-10-21版の標準辞書は256ルール（大文字・小文字を同一視した表記で252語）です。ネットスラング、ゲーム・Discordの略語、黒い砂漠の32職略称、27種の絵文字を収録しています。笑い・拍手は別途、文脈に応じたルールで処理します。

| 入力例 | 読み上げ用テキスト |
| --- | --- |
| `w` / `ｗ` | わら |
| `ww` / `www` / `ＷＷＷ` | わらわら |
| `（笑）` | わら |
| `8888` のみの投稿 | パチパチ |
| `kwsk` / `wktk` | クワシク / ワクテカ |
| `おｋ` / `GJ` | オーケー / グッジョブ |
| `うp主` | ウプヌシ |
| `CC` / `CT` | シーシー / シーティー |
| `覚醒WTで拠点戦` | カクセイウィッチでキョテンセン |

英単語・URL・コード・操作キー中の `w` は笑いとして変換しません。発言者名には標準スラング辞書を適用せず、管理パネルで登録した個別辞書のみを適用します。個別辞書は標準辞書より優先し、置換後の文字を再び変換しません。

管理パネルの「辞書一覧」で標準辞書の件数と個別登録を確認できます。「辞書追加」「辞書削除」からサーバー独自の読みを調整できます。

### 黒い砂漠の職略称の設定

環境変数 `TTS_READING_PROFILE` で職略称の読み方を選びます。

| 値 | 職略称の扱い |
| --- | --- |
| `auto`（既定） | 「黒い砂漠」「拠点戦」「ソラレ」などの明確な用語、または `覚醒WT`・`伝承WZ` などの組み合わせが同じ投稿にある場合に展開 |
| `general` | 黒い砂漠の職名への展開を行わない |
| `black_desert` | 大文字の職略称を常に展開。`SP` は引き続き職名を示す周辺表記が必要 |

`SP` 単独は「エスピー」です。`auto` では黒い砂漠の文脈を確認したうえで、`覚醒SP`、`SPクラス`、`[SP]` などの局所的な表記がある場合のみ「セラフィム」にします。

辞書は出典を確認して収録した固定データです。起動時・メッセージ受信時にネットから単語を自動収集したり、LLMを呼び出したりしません。出典、読みの判断基準、追加方法は [読み上げ辞書の仕様](docs/pronunciation-dictionary.md) を参照してください。

## 辞書の検証とデプロイ時の状態保全

Node.js 22.12.0以降で `npm test` を実行します。笑いの誤変換、URL・操作キー・発言者名の保護、個別辞書の優先順位、職略称の文脈、絵文字・長文処理を検証します。

2026-10-21に本番の `DATA_DIR/state.json` を退避し、永続Volumeの `/data` へ移行しました。復元後のファイルが退避前と一致することも確認しています。このファイルには個別辞書、サーバー設定、利用者設定、お気に入りなどが含まれます。**今後の更新でもこのVolumeを維持し、Volumeの削除・交換や別環境への移行前には状態をエクスポートしてください。** 一時ディスクで動いている新しい環境の移行手順は [状態を保全して反映する手順](docs/pronunciation-dictionary.md#状態を保全して反映する手順) を参照してください。
